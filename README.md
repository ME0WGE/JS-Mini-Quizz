📌 Détails du projet : Mini Quiz en JavaScript
Attention: vous ne pouvez utilisé que ce qui a été vu sur Molearning en terme de variable ou méthode. (Variable, tableaux, condition, boucles)
Nom du projet GitHub : JS-Mini-Quizz
Technologies : HTML, CSS, JavaScript (Bootstrap autorisé)
Thème du quiz : Libre (vous choisissez le sujet)
Nombre de questions : Minimum 10
Affichage du score : Nombre de bonnes réponses enregistrées et affichées à la fin
|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Présentation de la page web :
Un titre principal
Un header
Un footer

Stockage du projet : GitHub avec au minimum 10 commits
À la fin du jeu : Une alerte doit afficher le score et annoncer la fin du quiz

En pratique
Sur votre site dans la console, le quizz démarre et pose les questions. Les réponse sont écrite par l'utilisateur directement dans la console. Les points sont compté, a la fin une alerte indique la fin du quizz et le score.
